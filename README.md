# 🟣 Lucid Math

A clean, ad-free, animated purple unblocked games site.

## Features
- Live animated purple gradient background
- Glassmorphism UI + smooth hover effects
- Search + category filters
- Fullscreen in-site game player (no redirects)
- 100% static — no build tools, no server

## Adding games
Edit `games.js` and add to the `GAMES` array:

\`\`\`js
{ name: "Game", emoji: "🎮", tag: "Arcade", url: "https://example.com" }
\`\`\`
